In the maquiladora (Settings, Companies, Inter-Company):

- enable **Create Sale Orders when buying to this company** and, if wanted,
  the automatic validation of the sale orders;
- set an inter-company sale user that belongs to the maquiladora and is at
  least Sales user, Inventory user and **Maquila User** (confirming a maquila
  order reads the program);
- give the matrix partner a pricelist in the currency of the purchase
  orders (usually USD).

In the matrix: set an inter-company invoice user and, if wanted, the
automatic validation of the vendor bills. Products must be shared between
the companies.

On each maquiladora, keep one active maquila program per foreign matrix and
list the products of the program, so that the right program is picked.
